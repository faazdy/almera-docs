# 1. Creación de un documento (Elaboración)

El proceso para crear un nuevo documento sigue un flujo de aprobación que inicia con una solicitud.

## Ruta

`Documentos → Elaborar → Documento específico`

## Pasos

1. Diríjase a:

   `Documentos → Elaborar → Documento específico`

2. Seleccione el proceso o subproceso al que quedará asociado el documento.

3. Ingrese el nombre del documento.

4. Seleccione la clase documental (guía, manual, política, etc.).

   > Si la clase no existe, consulte la sección **Creación de una clase de documento**.

5. Diligencie la justificación de creación.

6. Presione **Grabar** y posteriormente **Enrutar** para enviar la solicitud de aprobación.

7. Cuando la solicitud sea aprobada:

   - Abra **Mis pendientes**.
   - Seleccione el documento.
   - Pulse **Editar**.
   - Complete los campos faltantes (fecha, responsable, etc.).

8. Abra la plantilla Word y continúe la edición desde el editor en línea.

> **Nota**
>
> El editor realiza guardado automático. No es necesario descargar el documento para conservar los cambios.

# 2. Creación de un emisor (interno o externo)

Permite registrar entidades emisoras como INVIMA u otros entes de control.

## Ruta

`Admin → Calidad → Clases y emisores de documentos`

## Pasos

1. Ingrese a **Admin → Calidad → Clases y emisores de documentos**.
2. Seleccione **Crear emisor**.
3. Registre el nombre.
4. Asigne un código.
5. Defina el origen:

- Interno
- Externo
- Ambos

6. Pulse **Grabar**.

---

# 3. Creación de una clase de documento (tipos)

Permite crear nuevos tipos documentales como Protocolos, Manuales, Guías, etc.

## Ruta

`Admin → Calidad → Clases y emisores de documentos`

## Pasos

1. Ingrese al módulo.
2. Seleccione **Crear clase**.
3. Registre:

- Nombre
- Código (siglas)

4. Defina el origen:

- Interno
- Externo
- Ambos

5. Configure si:

- Es un formato.
- Participa en el flujo de aprobación.

6. Adjunte la plantilla Word (.doc).

7. Presione **Grabar**.

---

# 4. Modificación de la jerarquía de un proceso

Permite mover un subproceso a otro proceso padre.

## Ruta

`Admin → Procesos`

## Pasos

1. Abra **Procesos**.
2. Seleccione el subproceso.
3. Cambie el campo **Padre**.
4. Pulse **Grabar**.

> **Importante**
>
> El mapa de procesos se actualiza automáticamente. No es necesario reemplazar la imagen.

---

# 5. Actualización y vinculación del mapa de procesos

## Pasos

1. Reemplace la imagen del mapa desde **Administrar archivos**.
2. Abra **Administrar áreas**.
3. Desde otra pestaña copie la URL de la pestaña **Seguimiento** del proceso.
4. Pegue dicha URL en el campo **Dirección** del área correspondiente.
5. Pulse **Grabar**.

> **Advertencia**
>
> Cada área del mapa debe vincularse manualmente. Al reemplazar la imagen, las áreas anteriores no se conservan.

---

# 6. Gestión de términos y definiciones

## Ruta

`Admin → Calidad → Términos y definiciones`

## Pasos

1. Abra el módulo.
2. Registre el término.
3. Escriba la definición.
4. (Opcional) indique la fuente.
5. Pulse **Grabar**.

## Notas importantes

- El editor de documentos guarda automáticamente.
- El flujo documental requiere aprobación antes de la edición final.
- Las plantillas se cargan en formato Word (.doc).
- El mapa de procesos requiere vinculación manual de cada área.
